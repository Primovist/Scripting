# Changelog

## 1.3.2 — 2026-08-21

### 修复

- 修复 Surge 模块开关请求缺少请求头和 JSON 请求体的问题。
- 恢复 `X-Key` API 密钥鉴权。
- 恢复 `/v1/modules` 请求体，正确传递“交管12123”模块的启用状态。
- 支持根据配置选择 HTTP 或 HTTPS Surge API。
- HTTPS 请求支持 Surge 本机证书场景，并增加 HTTP 状态码错误检查。
- 空密码时不再发送空的 `X-Key` 请求头。

### 配置

- Surge HTTP API 端口、协议和密码继续从 index 页面读取并保存。
- 默认协议为 HTTP，默认端口为 `6166`，密码默认留空；如果 Surge 配置了 API 密码，需要在 index 页面填写对应密码。

### 技术

- Surge API 请求超时时间调整为 8 秒。
- 已通过 TypeScript 类型检查。

## 1.3.0 — 2026-08-16

### 新增

- Token 失效卡片点击后改为进入 Scripting 内部刷新流程，不再直接跳转支付宝。
- 增加 `scripting://run_single/12123?action=refreshToken` 刷新入口。
- 自动刷新流程会打开支付宝交管 12123，等待 20 秒后读取 BoxJS 中的 `wx_12123`。
- Token 更新后自动重新请求 12123 接口，并调用 `Widget.reloadAll()` 刷新所有小组件。
- Token 验证成功后自动关闭 Surge“交管12123”模块。

### 修复

- 修复透明背景组件支持，透明、模拟透明和模糊背景模式下不再绘制不透明蓝色底色。
- 修复透明背景模式下白色文字、图标、卡片边框的显示。
- 修复 Token 失效点击入口与 Scripting 内部流程的衔接。

### 技术

- 使用 Scripting URL Scheme、`Script.queryParameters`、`Widget.reloadAll` 和延时任务完成刷新流程。
- 保留普通背景模式和透明背景模式的差异化绘制。
- 已通过 TypeScript 类型检查。

## 1.2.1 — 2026-08-15

### 新增与优化

- 增加 Surge HTTP API 端口和密码配置，可在 index 页面设置并保存到 Keychain；默认端口为 `6166`，密码默认留空。
- Surge 模块控制改为读取用户配置的端口和密码，用于 Token 失效时开启“交管12123”模块、Token 有效时关闭模块。
- 增加多尺寸预览功能，可在 index 页面选择小、中、大、超大、圆形、矩形或行内组件进行预览。
- 小尺寸组件增加参数校验：未设置或设置错误时保留原有卡片外框和背景，仅将内容替换为参数提示。
- 参数提示内容为：`V：车辆信息`、`L：驾照信息`。
- 修复矩形配件和行内配件预览及布局适配问题。
- 优化行内进度条填充范围、分度显示和右侧 12 分刻度。

### 技术

- 完成 index 页面保存逻辑整理，点击“完成”会保存全部配置。
- 已通过 TypeScript 类型检查。

## 1.2.0 — 2026-08-15

### 新增

- 增加 `accessoryCircular` 圆形锁屏组件：左右半圆圆环分别显示违法数量和累计扣分。
- 圆形组件支持 18 个分度，右侧突出显示 12 分刻度。
- 增加 `accessoryRectangular` 矩形锁屏组件，显示四行核心信息：未处违法、累计扣分、年检日期、换证日期。
- 增加 `accessoryInline` 行内锁屏组件，以无文字进度条显示违法和扣分数据。

### 优化

- 圆形进度条改为圆环绘制，进度尾部采用圆润过渡。
- 圆形组件中心文字改为汉字与数字分行显示，并缩小文字区域避免覆盖圆环。
- 行内进度条改为从中心向左右两侧填充，支持 18 个分度和右侧 12 分刻度。
- 行内进度条移除底色轨道，只保留实际进度颜色填充。
- 矩形锁屏组件移除底色和卡片布局，使用透明背景显示四行文字。
- 增加 `systemExtraLarge` 超大组件，复用中尺寸左右双卡片布局，并放大内容和边框。
- `systemLarge` 调整为上下布局，上方显示车辆信息，下方显示驾驶证信息。
- 车辆和驾驶证信息卡片统一采用圆角矩形描边，避免裁剪导致边框中断。
- 车辆、驾驶证图标统一使用白色，日期字段显示完整年份。

### 技术

- 配置页在“完成”按钮上方增加预览类型选择器，支持预览小、中、大、超大、圆形、矩形和行内组件。
- 使用 Scripting `Canvas` 绘制圆环、分度线和行内进度条。
- 增加不同 Widget family 的独立布局分支和尺寸适配。
- 优化 Canvas 进度填充、圆润线帽和锁屏组件文字缩放。
- 已通过 TypeScript 类型检查。

## 1.1.0 — 2026-08-15

### 新增

- 完成从 Scriptable 到 Scripting 的 12123 小组件迁移，使用 `widget.tsx` 和原生 TSX 页面。
- 增加 BoxJS 自动读取 `wx_12123` Token，并保存到本机 Keychain；支持配置 BoxJS 域名和手动立即同步。
- 增加 Surge HTTP API 联动：检测到 Token 失效时自动开启“交管12123”模块，请求成功后自动关闭模块。
- 增加 Token 失效卡片提示，点击小组件可打开支付宝交管 12123 小程序。
- 增加 `vehicles` 和 `othersVehicles` 车辆枚举，支持在配置页选择展示车辆。
- 增加小组件参数：小尺寸和大尺寸支持 `V` 展示车辆信息、`L` 展示驾驶证信息；中尺寸固定左右同时展示两类信息。
- 增加车辆年检日期和驾驶证换证日期展示。

### 优化

- 中尺寸组件按车辆信息 / 驾驶证信息左右双卡片布局重构。
- 卡片增加统一蓝色背景、白色圆角描边、白色图标和内缩边框。
- 优化卡片宽高、间距、字体大小和 `minScaleFactor`，提升不同小组件尺寸下的完整显示效果。
- 车辆信息顺序调整为：车辆状态、未处违法、上次更新、年检日期。
- 驾驶证换证日期和车辆年检日期显示完整年份。
- Token 失效时保留原卡片颜色、图标和边框样式，仅替换卡片内容为更新提示。
- 配置页显示已读取车辆数量，并将其放置在“刷新车辆列表”按钮前，使用系统常规颜色。

### 技术

- 使用 Scripting `Widget.present`、`Navigation`、`Picker`、`Keychain` 和 `fetch` API。
- 增加接口失败缓存回退和车辆选择持久化。
- 已通过 TypeScript 类型检查。
