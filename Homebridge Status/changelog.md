# Changelog

## [1.1.2] - 2026-09-06

### Changed

- 新增浅色与暗色模式动态配色支持。
- 浅色模式采用天空蓝到海蓝的反向渐变背景，并优化文字与图标颜色以提高可读性。
- 调整 CPU、内存图表刻度及上下界横线在浅色模式下的颜色和透明度。
- 暗色模式继续保留深紫色渐变背景。

## [1.1.1] - 2026-08-21

### Changed

- 将“运行状态”和“插件更新”向左移动，使其与内存图标对齐。

## [1.1.0] - 2026-08-17

### Added

- 当 Homebridge、插件或 Node.js 有可用升级时，点按组件可打开连接设置中配置的 Homebridge 地址。

## [1.0.1] - 2026-08-15

### Added

- 支持透明背景和模糊背景组件模式。
- 在系统绘制背景的模式下自动保持组件内容透明，避免覆盖桌面壁纸。
- 使用 `widgetBackground` 适配普通组件、透明背景、模糊背景、锁屏组件及强调色模式。
