# Changelog

本文档记录「GitHub 上传」脚本的重要变更。

## 2026-08-24

### 新增

- 新增本人 GitHub 仓库查询功能，通过 `GitHub.listRepos` 获取当前账号拥有的仓库。
- 新增原生 `Picker` 仓库选择器，并使用 `navigationLink` 样式展示仓库列表。
- 私有仓库使用 SF Symbols `lock.fill` 图标标识。
- 选择仓库后自动填写仓库所有者、仓库名称及默认分支。
- 新增仓库内文件夹输入，可指定文件上传到仓库中的目标目录。
- 新增文件夹上传摘要，显示本次上传的文件数量和总大小。

### 调整

- 将仓库查询、仓库选择和仓库内文件夹输入从设置页移动到首页的「上传目标」区域。
- 将 Commit 提交信息设置从设置页移动到首页，并放置于上传按钮之前。
- 上传整个文件夹时不再逐项展示目录中的文件，仅展示所选文件夹及汇总信息。
- 单独选择的文件仍逐项显示文件名和文件大小。
- 文件夹摘要旁的「移除」按钮会一次移除该文件夹中的全部待上传文件。

### 修复

- 修复仓库查询返回 HTTP 422 的问题：不再同时向 `/user/repos` 传递 `affiliation` 和 `type`，改为仅使用 `affiliation: "owner"`。
- 修复上传文件夹时只上传内部内容、未保留所选文件夹根目录的问题。
- 文件夹上传现在会保留所选文件夹名称以及完整的子目录结构。
- 改进 iOS 文件提供程序兼容性，通过手动递归读取确保多层子目录中的文件能够被发现和上传。
