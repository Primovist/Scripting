# 更新日志

本项目的所有重要变更均记录于此。

## [1.1.0] - 2026-08-23

### 新增

- 新增 Type-C 外接模式识别，结合 `external_charging_flag`、`typec_attach_status` 与 `bat_otg_powerbank_status` 判断外接连接类型。
- 新增仅充电宝模式图标：在系统分档电池右下角显示橙色 `powerplug.fill`，表示对外供电。
- 新增网络外接模式图标：在系统分档电池右下角同时显示蓝色流量交换箭头与橙色电源插头，适用于仅供网及供网＋供电模式。

### 优化

- 电池主体颜色与外接状态小图标分离：电池仅表达电量和充电状态，附加图标分别表达网络链路与对外供电状态。
- 正常电量继续使用系统主文字颜色，低于 20% 使用红色，设备自身充电时使用绿色。
- 无法可靠区分“仅供网”和“供网＋供电”时，两者统一使用网络外接模式图标，避免误报具体供电状态。

## [1.0.3] - 2026-08-23

### 优化

- 蜂窝信号图标改为根据设备返回的 0–5 级信号动态映射至系统四格信号的 0%、25%、50%、75% 和 100% 填充状态。
- 移除蜂窝信号图标后重复显示的信号格数字，使顶部状态栏更接近系统样式。
- 将 QCI 从中间信息栏移动至顶部信号图标后方，并改为圆圈内显示 QCI 数字。
- QCI 圆圈和数字使用系统主文字颜色，自动适配浅色、深色及透明背景模式。
- 缩小 QCI 指示器并微调数字位置，使其与蜂窝信号图标在尺寸和视觉中心上保持协调。
- 无法解析有效 QCI 时自动隐藏圆形 QCI 指示器。

## [1.0.2] - 2026-08-23

### 优化

- 增强透明背景与模糊背景小组件的可读性：保持整体背景透明，并为中间两行状态信息添加 50% 不透明度的自适应衬底。
- 优化电池状态显示，继续使用原生 SF Symbols，并按最接近的 0%、25%、50%、75% 和 100% 档位显示电池余量。
- 充电状态使用绿色带闪电电池图标；未充电的正常电量使用系统主文字颜色；低于 20% 时使用红色。
- 电池电量未知时显示红色空电池，并在电池中央显示红色感叹号。

## [1.0.1] - 2026-08-22

### 修复

- 移除系统版本号前错误显示的 `UFI` 前缀。
- 修复正常电池使用固定白色时，在浅色背景下对比度不足的问题。

## [1.0.0] - 2026-08-22

### 首次发布

- 提供适用于 Scripting 的 **U60 Pro 中号桌面小组件**。
- 提供原生 iOS 风格的配置页面，可设置 WebSSH-u60pro 地址、用户名和密码。
- 支持 WebSSH 根路径及自定义 `WebBaseDir` 地址。
- 密码保存至当前脚本隔离的系统钥匙串，不写入普通配置存储。
- 支持 JWT 登录、令牌缓存、响应令牌续期，以及认证失效后的自动重新登录。
- 提供“测试连接”功能，并显示设备、网络及当日流量摘要。
- 提供中号小组件预览和保存后刷新已安装小组件的功能。
- 主设置界面关闭或收起后立即终止脚本实例，避免继续在后台运行。

### 小组件信息

- 显示设备型号、固件版本、蜂窝信号格数、电池电量和充电状态。
- 显示今日流量及本月累计流量，并自动使用 MB 或 GB 单位。
- 显示运营商名称和当前移动网络类型。
- 显示当前 5G NR 或 LTE 信号频段。
- 显示 QCI；数据来自 `/api/net/ambr/get`，无法解析到有效数字时自动隐藏该项。
- 显示 CPU 使用率和内存使用率。
- 显示 CPU 温度与电池温度，格式为 `CPU温度|电池温度`。
- 温度图标根据两项温度中的最高值动态变色：
  - 不高于 50℃：绿色
  - 高于 50℃、低于 70℃：黄色
  - 达到或高于 70℃：红色
- 显示当前 Wi‑Fi SSID 和 Wi‑Fi 频段（2.4G 或 5G）。
- 显示无线客户端数量和未读短信数量。
- 显示 RSRP、RSRQ、SNR 及最后更新时间。

### 交互与可靠性

- 点击小组件任意位置即可通过 App Intent 请求刷新。
- 网络请求失败时优先显示最近一次成功获取的缓存数据，并标记为陈旧状态。
- 无缓存时显示可读的错误摘要和空状态数据。
- 对短信和 QCI 等非关键接口进行独立容错，避免其失败影响主要状态展示。
- 短信与 QCI 数据并行请求，减少额外等待时间。
- 仅支持中号小组件；其他尺寸会显示明确提示。

### 界面与布局

- 使用 SwiftUI 风格的 Scripting 原生组件构建界面。
- 使用系统按钮、语义化颜色和 SF Symbols。
- 小组件背景、信息衬底及分隔线分别采用 `systemBackground`、`secondarySystemBackground` 和 `separator`，由系统自动适配浅色与深色模式。
- 主要与次要文字分别采用 `label` 和 `secondaryLabel`，提高深色模式下的对比度与可读性。
- 网络、Wi‑Fi、CPU、内存、客户端及 QCI 图标统一使用协调的 iOS 系统色，不再手工维护独立深色调色板。
- 温度、电池、短信及数据刷新状态统一采用 `systemGreen`、`systemOrange` 和 `systemRed` 表达正常、警告与危险状态。
- 两行状态信息采用统一高度、间距、圆角和图标占位尺寸。
- 状态文字根据两行内容和小组件可用宽度计算统一动态字号，避免各信息项字号不一致。
- 配置表单采用左侧标签、右侧输入框布局，输入内容右对齐。
- 支持浅色与深色外观，并通过 iOS 语义化颜色自动适配系统显示模式。
